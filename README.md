# حكايتنا — موقع هدية رقمية

هذا مشروع ويب عربي رومانسي، تم إنشاؤه كهدية شخصية من عبيدة إلى سجود. المشروع يضم:

- شاشة افتتاحية أنيقة
- صفحة قصتنا مع فصول متدرجة
- رسالة ورقية داخل ظرف رقمي
- قسم يوم عقد القران بتاريخ 16 أكتوبر 2026
- بطاقات أحلام مستقبلية
- ظرف أخير يحتوي رسالة خاصة

## التشغيل محليًا

1. افتح الطرفية داخل مجلد المشروع.
2. شغّل الخادم التالي:

```bash
python3 -m http.server 8000
```

3. افتح المتصفح على الرابط:

```text
http://localhost:8000
```

## هيكل المشروع

- `index.html` — الصفحة الرئيسية
- `styles.css` — التصميم والستايل
- `script.js` — المنطق التفاعلي
- `data/content.js` — محتوى القصة والرسائل والأحلام

## تعديل النصوص

يمكنك تعديل كل المحتوى الشخصي بسهولة من ملف `data/content.js`:

- فصول القصة
- نص الرسالة الأساسية
- نص الرسالة الأخيرة
- بطاقات الأحلام

## الملاحظات

- تم تصميم الموقع ليكون Mobile First وداعمًا لـ RTL.
- لا يوجد أي backend أو قاعدة بيانات.
- مناسب للنشر عبر HTTPS كصفحة ثابتة.
- تم اختيار HTML/CSS/JavaScript لأن الموقع هدية شخصية، وليس متجرًا أو تطبيقًا تجاريًا.

## لماذا هذا الخيار الأفضل هنا؟

بالنسبة لمثل هذا المشروع، فإن الموقع الثابت هو الخيار الأمثل لأنه:

- سريع وسهل التشغيل
- لا يتطلب خدمات أو تكوينات معقدة
- مناسب جدًا للهدية الشخصية
- يسمح بالتعديل السريع للنصوص
- يضمن الخصوصية والسرعة مع الحفاظ على التصميم الاحترافي
